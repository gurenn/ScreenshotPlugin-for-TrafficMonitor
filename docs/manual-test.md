## 11. 破坏性注入方法（用于把失败路径变成可复现）

| 目标 | 做法 |
| --- | --- |
| 目录不可写 | 设置里把保存目录改成 `C:\Windows\System32\drivers`（普通用户不可写） |
| 写入失败（`kErrWrite` / `0x8008`） | 截图前用另一个进程独占目标文件（不共享写），或用 `icacls` 去掉目标目录的写权限但保留可创建 |
| WIC 工厂失败（`0x8006`） | 在精简镜像里禁用 `WindowsCodecs.dll`（重命名需管理员且会破坏系统，**仅在专用测试机**做）；或临时把 `CLSID_WICImagingFactory` 相关注册项移除 |
| 编码器不可用（`0x8007`） | 把 `format` 手工改成尚未支持的值会被回退，故此码难以人工触发；以日志/单测方式覆盖即可 |
| 图像过大（`0x8004`） | 用 3 台 4K 屏 + 200% 缩放把虚拟屏幕推到接近 32767 边；或临时把 `kMaxImageBytes` 调小后重建（仅测试） |
| 安全桌面（`0x8005`） | 触发截图的同时按下 `Ctrl+Alt+Del` 切到安全桌面；或锁屏后由热键触发 |
